## ⚠️ 重要限制报告：无法在库内区分 EXACT / SERIES

按你的规则 9、10 与「重要」段落，我**没有扩表**。如实报告限制：

**技术事实**：`product_images` 只有 `id / product_id / url / sort` 四列，**没有任何字段可保存** `source`、`license`、`match_type`。因此库内**无法区分**哪张是精确型号图、哪张是系列参考图。

**前端现状**（已检查）：`frontend/src/` 中**完全没有** `matchType` / `source` / `license` / `系列参考` 等概念；详情页结构为

```vue
<div class="images">
  <img :src="mainImage" :alt="product.name" />   <!-- 单图，无角标、无图注 -->
</div>
```
图片取值由 `src/utils/image.ts` 的 `pickProductImage()` 统一负责（优先非占位图）。

**结论**：若要真正区分 EXACT/SERIES，**必须扩表或加一张映射表**，属于你明确禁止的"擅自扩表"。因此本轮**未实施前端提示**——因为没有数据源可供判断，硬编码会立刻失真。前端展示逻辑**保持原样**。

**风险提示**：#5、#8、#45 这三条是"系列图"（Xiaomi 14 而非 14 Ultra、vivo X100 而非 X100 Ultra、BenQ 通用显示器），前端目前会**无差别地当作产品图片展示**。若你认为这不可接受，最小补救方案是**回滚这 3 条**（`DELETE` 按已记录的 imageId 43065/43066/43068），其余 7 条（含 1 条 EXACT）风险较低。**等你指示，我不擅自操作。**

## E. 类别示意图方案

### 设计原则

**能做示意图**：仅表示"这是某一类产品"，**不暗示具体品牌型号**；前端必须以"示意图"文案或角标明示。

**绝对不能冒充**：任何会让人以为"这就是该型号实拍"的用法。**示意图不得**：带品牌 logo、带可见型号铭牌、用于参数对比页、用于排行榜/评测语境。

### 关键判断

1. **没有一类能找到"无品牌、现代、且主体干净"的通用示意图。** Commons 上的通用品类图基本都带可见品牌字样，或年代久远（PowerBook G4、3Com、PS3 肥机、Pentium 4）。用它当示意图，**反而比灰色占位图更容易误导**——用户会以为产品是那个牌子/那个年代。
2. **显卡类精筛后 0 条合格**（唯一候选是 PCI-E SSD），说明"干净通用图"并非每类都有。
3. **方案的真实价值有限**：

| 方案 | 覆盖率 | 代价 |
|---|---|---|
| 现状（不用示意图） | 50/132 = **37.9%** | — |
| 用"带品牌通用图"当示意图 | 132/132 = **100%** | 误导风险高（用户以为产品是该品牌/年代） |
| 用"无品牌干净图"当示意图 | 仅手机/显示器/台式/平板等少数类能凑 | 覆盖提升有限 |
| 用**统一的自绘/纯色类别图标** | 132/132 = **100%** | ✅ **推荐**：零误导、零版权风险、视觉上明确是"占位示意" |

## F. 预计真实视觉覆盖率

需要区分两个概念，避免把"覆盖率数字"当成"真实图片"：

| 口径 | 当前 | 若采用类别示意图 | 说明 |
|---|---|---|---|
| **真实产品图片覆盖率** | **50/132 = 37.9%** | **不变，仍 37.9%** | 示意图**不是**真实产品图，不应计入 |
| **非灰图（有视觉内容）覆盖率** | 50/132 = 37.9% | **132/132 = 100%** | 但其中 82 张是"示意图"，非实拍 |

**诚实结论**：类别示意图**只能消除"灰色占位图"的观感**，**不能提高真实图片覆盖率**（仍是 37.9%）。

而且，用 Commons 上带品牌的老旧通用图做示意图，会把"灰图"问题换成"误导"问题——**这比灰图更糟**。

### 我的建议（按推荐度）

1. **首选：自绘类别图标**（SVG 线稿/纯色 + 类别名）。100% 消除灰图、零误导、零授权风险，且明确表达"暂无实拍图"。这是唯一既提升观感又不撒谎的方案。
2. **次选：保留现状 + 前端加"暂无实拍图"文案**。最诚实，工作量最小。
3. **不建议**：拿带品牌的 Commons 通用图当示意图。
4. **真正的覆盖率提升**只能靠：更换网络环境后用 Openverse、采购商用图库授权、或人工拍摄/众包。
