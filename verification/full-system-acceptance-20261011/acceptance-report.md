## 2. 发现并修复的问题

| 级别 | 问题 | 修复 |
|---|---|---|
| **P1** | **详情页价格历史图表从未渲染**：`renderChart()` 在 `loading=true` 期间调用，此时图表容器尚未渲染（`v-if="loading"` 骨架屏），`chartRef` 为 null 直接 return，且之后无人再调用——历史价格图表功能实际失效 | 移到 `loading=false` 后 `await nextTick()` 再初始化 |
| **P2** | **用户端无路由守卫**：未登录访问 /profile、/profile/favorites、/profile/history 不跳转，页面静默 403 | 新增 `router.beforeEach`（受保护路由名单 + 登录页回跳 redirect，防开放重定向） |
| **P2** | **无效/过期 token 处理不完整**：拦截器仅清 token 不跳转，用户停留在空页面 | `request.ts` 401/403 双分支统一 `forceRelogin()`：清 token + 提示 + 跳转登录（已在登录页不跳，防循环） |
| **P2** | **列表页 URL 筛选参数丢失**：`onMounted` 只映射 keyword/categoryId/sort，**brandId/minPrice/maxPrice 被忽略**（分享/直达 URL 筛选失效，实测 12 条未过滤） | 补全三个参数映射；修复后实测筛选生效 |

未修复但如实记录（P3/设计取舍）：
- 对比列表为 Pinia 内存态，整页刷新即清空（对比操作本身不受影响，属既有设计）
- 管理端**尚无图片授权/待审核图片管理界面**（后端授权表与 API 已就绪，管理 UI 未实现——如实声明，未伪称完成）
- 管理端无同步任务 UI（同步后端 API 可用，本轮经 API 验证）
