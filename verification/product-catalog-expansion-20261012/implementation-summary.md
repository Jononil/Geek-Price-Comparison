## 4. 数据导入方式

**幂等导入脚本**：`_expand.mjs`（本目录内）

流程：
1. 从商品清单读取待扩充产品（第一波 67 项 + 第二波 96 项）
2. 通过 Commons API 检索候选图（最多 3 个查询词，含品牌+型号+分类）
3. **严格核验**：品牌身份 + 完整型号匹配 + 变体词一致性 + 容量一致性 + 主体标志（排除拆机图/对比图/截图/包装/Logo 等）+ 开放许可 + 署名完整性
4. 插入商品（幂等：商品名已存在则跳过）
5. 插入图片（幂等：URL 已存在则跳过）
6. 插入授权记录（幂等：image_id 已有记录则跳过）
7. 补齐仿真报价（3 平台：京东/淘宝/拼多多）、90 天历史价格、5 条规格

**报价数据**：`product_prices` 表中新增商品的报价 URL 指向 `https://item.example.com/{id}`，`shop_name` 为「京东自营」「天猫旗舰店」「拼多多百亿补贴」等**系统模拟**值，不代表真实平台实时价格。历史价格使用随机游走算法生成（`source='SIMULATED'`），日期覆盖最近 90 天。

**规格数据**：按分类模板生成 5 条规格（屏幕/处理器/内存/硬盘/接口等），**系统模拟**值，非官方参数。

## 7. 未达标/阻塞原因

### 未达到 100 个可展示商品？
**已达到**：107 个（目标 100）。

### 显示器与台式电脑分类可展示数为 0
**原因**：现有商品（LG 27GP95RP、微星海皇戟、华硕玩家国度台式等）均为中国特供型号，Commons 上无对应产品照片。已扩充 Dell U2415/U2412M/OptiPlex 7090 等国际型号，但候选池为空或无通过核验的图片。

**建议**：若需覆盖这两类，需扩展到其他开放图片源（如 Pexels、Unsplash）或使用本地拍摄图片，但需人工核验主体与授权。

### 部分商品无通过候选
第二波中 89 项检索后无通过核验的候选图片，主要为：
- 中国特供型号（机械革命翼龙、泰坦军团、漫步者 NeoBuds 等）
- 新款产品（2024 年后发布的机型，Commons 覆盖滞后）
- 候选池中存在但主体不符（拆机图/对比图/截图/配件图等）
