# 阶段 B-1 · 前端署名展示方案（仅设计，未改代码）

> 生成时间：2026-10-10T16:24:56.181Z
> 现状核验：8 个产品图入口全部经 `components/ProductImage.vue`（详情页/首页卡片/列表/排行/对比/推荐/收藏/历史）；该组件只接收 URL，无任何许可信息。

## 一、设计原则

1. **署名与具体图片记录绑定**，不与商品绑定——同一商品不同图片可能许可不同（对比页/详情页取图逻辑不同，各自可追溯）。
2. 卡片保持整洁，长文本只出现在详情页/弹窗。
3. 署名必须**可见、可点开**（作者、许可链接、原始页面三个出口）。
4. 衍生图（缩放）按 CC 要求说明改动。

## 二、逐页面方案

### 2.1 商品详情页（ProductDetailView.vue）——主署名位

图片下方新增可折叠「图片信息」条（默认收起）：

```
┌──────────────────────────────────────────┐
│  [商品大图]                                │
│  ⓘ 图片来源与许可                    ▾     │  ← 点击展开
├──────────────────────────────────────────┤
│  作者：Henry Söderlund                     │
│  许可：CC BY 2.0（creativecommons.org…）   │  ← 外链
│  来源：Wikimedia Commons（文件页链接）      │  ← 外链
│  说明：展示图为官方 500px 缩放版            │
└──────────────────────────────────────────┘
```

- 数据来源：详情接口新增的 `imageAttribution[]`，按当前展示 URL 匹配。
- 系列图角标（已实现）与署名条共存：角标管"型号口径"，署名条管"版权义务"，互不替代。

### 2.2 商品卡片 / 列表 / 排行 / 推荐（ProductCard 等）

- **不显示文字**（保持整洁）。
- 卡片图右下角加 12px 的 ℹ 图标（半透明），点击跳转到该商品详情页锚点，或弹出 mini 气泡显示一行：`图：作者 · CC BY-SA 4.0`。
- 备选（更简）：卡片完全不加，署名义务集中由详情页履行——**CC 署名要求是"合理可达"，同一站点内点击可得即视为可达**，但保守起见建议保留 ℹ 入口。

### 2.3 对比页（CompareView.vue）

- 对比页可能同时展示多个商品的不同来源图：表头每列图片下方加一行 10px 灰字 `作者 · 许可`，点击展开该列完整署名。
- 数据来源：compareStore 存 Product 对象时带上 `imageAttribution`（后端 DTO 已扩展则自动携带）。

### 2.4 收藏 / 历史 / 推荐页

- 列表行内不加长文本；点击进入详情页后由详情页署名条统一履行。

### 2.5 管理后台

- 图片管理列表增加"授权状态"列（APPROVED / 需署名 / 待复核 / 已拒绝），支持按状态筛选与人工复核（填写 reviewer/reviewed_at）。

## 三、改动说明（modifications 字段）的展示

- 缩略图：`展示图为 Wikimedia 官方缩放版（500px），内容未编辑`——CC BY/BY-SA 对纯机械缩放通常无额外义务，但写明更稳妥。
- 若未来自建衍生图（裁切/压缩托管），必须在 modifications 写明处理方式，且 BY-SA 图的衍生需以同许可分享（这是方案中自建衍生图的主要成本，见 large-image-review.md）。

## 四、与展示资格的联动

- 后端详情接口**只下发** `audit_status ∈ {APPROVED, APPROVED_WITH_ATTRIBUTION}` 的图片 URL；PENDING/REJECTED 的图不出现在前端。
- 这样前端无需理解许可规则，只需负责"展示已合规的图 + 显示其署名"。
